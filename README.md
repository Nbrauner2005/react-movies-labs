# React Movies App 

## Overview
This project is a React-based movie application developed for my Web App Development 2 module. It uses the TMDB API to display
movie information and allows users to explore movies, actors and recommendations.

## Features
- Discover, Popular, Top Rated, Upcoming and Now Playing Movies.
- Movie details, cast information and actor profiles.
- Movie recommendations and actor filmographies.
- Favorites and Watchlist functionality.
- Search, genre filtering and sorting.
- Pagination and responsive navigation.

## Technologies
React, Vite, Material UI, TanStack React Query, React Router and TMDB API.

## Running the Application
From the movies directly, run:
- npm install
- npm run dev

A valid TMDB API key is required
