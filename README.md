# React Movies App 

## Overview
This project is a React-based movie application developed for my Web App Development 2 module at SETU.
It uses the TMDB API to to retrieve movie and actor informaton, allowing users to browse movies, discover recommendations and
manage personal movie collections.

## Features

**Movie Browsing**
- Discover, Popular, Top Rated, Upcoming and Now Playing movies.
- Detailed movie information, cast and recommendations.
- Actor profiles with biographies, cast and recommendations.
- Navigation between movies, actors and related movies.

**Additional Functionality**
- Favorites and Watchlist collections.
- Watchlist persistence using localStorage.
- Movie title searching and genre filtering.
- Pagination on the Discover Movies page.

 **User Interface**
 - Responsive layout using Material UI.
 - Redesigned movie cards and navigation bar.
 - Mobile navigation menu and active-page highlighting.

## Technologies Used
- **React and Vite** - Application Development
- **Material UI** - Components, styling and responsive layouts.
- **TanStack React Query** - API data fetching and caching.
- **React Router** - Navigation between pages.
- **TMDB API** - Movie and actor information.

## Installation and Setup
1. Clone the GitHub repository.
2. Navigate to the movies directory.
3. Install the dependencies.
4. Configure a valid TMDB API key.
5. Start the development server.

   cd movies
   npm install
   npm run dev

## Project Structure
- src/api/ - TMDB API functions.
- src/components/ - Reusable interface components.
- src/pages/ - Application pages.
- src/contexts/ - Favorites and Watchlist state management.
